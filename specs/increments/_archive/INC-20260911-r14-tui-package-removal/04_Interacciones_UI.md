# 04 Interacciones UI

## Objetivo del documento

Describir la respuesta de la interfaz ante intentos de invocar la interfaz TUI retirada.

## Interacción en CLI

Invocación:
```bash
axiom tui
```
Respuesta:
```
error: unknown command 'tui'
```
La interfaz guiada vigente es el launcher web accesible con:
```bash
axiom app
```
