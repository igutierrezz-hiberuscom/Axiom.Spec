# 04 Interacciones UI

El panel muestra audit/project activity y `recentEvents` newest-first. Counters del proceso viven en sección titulada “Métricas del proceso”, nunca bajo el proyecto. Ausencia/corrupción se distingue sin mostrar líneas crudas. No existe bloque ni acción de lessons.

La regresión final valida que sesión, preview token, delivery, IDs y enlaces se comportan igual desde UI y API; errores no rearman confirmación ni ocultan el resultado local.
