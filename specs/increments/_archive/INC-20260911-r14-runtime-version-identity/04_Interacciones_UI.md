# 04 Interacciones UI

## Objetivo del documento

Describir la presentación de la versión en CLI y upgrade.

## Salidas de interfaz

Invocación:
```bash
axiom --version
```
Salida:
```
0.1.0
```
Invocación de upgrade preview:
```bash
axiom upgrade --dry-run
```
Salida:
```
[axiom upgrade] Versión actual: 0.1.0 → Versión target: 0.1.0
No hay migraciones pendientes para la versión actual.
```
