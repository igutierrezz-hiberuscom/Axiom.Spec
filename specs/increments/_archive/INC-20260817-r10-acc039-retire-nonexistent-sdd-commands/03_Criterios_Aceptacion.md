# 03 Criterios de Aceptación

## Criterios de aceptación

- [x] Catálogos, contratos materializables y process surfaces activos dejan de emitir las tres formas inexistentes.
- [x] Las instrucciones activas usan exclusivamente los comandos reales correspondientes.
- [x] Tests focalizados cubren la ausencia de promesas inválidas y/o los replacements.
- [x] Los 19 intents internos y referencias archivadas no se eliminan.

### Happy path

Un proyecto materializado recibe instrucciones ejecutables con los comandos SDD reales.

### Validaciones y errores

Los barridos y pruebas distinguen superficies activas de historia archivada.

### Permisos y visibilidad

Sin cambios.

### Estados y efectos observables

Sin cambios de workflow; solo cambia el contrato documental/materializable público.
