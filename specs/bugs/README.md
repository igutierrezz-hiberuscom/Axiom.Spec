# Bugs

Cada bug de Axiom debe vivir en su propia carpeta.

## Baseline mínima

1. `README.md`
2. `metadata.yml`

## Cuando el bug gana entidad

Se añaden artefactos específicos de requisitos, criterios, contexto o plan según necesidad real.

## Archivado

Cuando un bug se cierra, su carpeta se mueve físicamente a
`bugs/_archive/<ID>/`. No se mantiene una copia activa ni se elimina el
registro histórico. La raíz de `bugs/` refleja únicamente el trabajo vivo.
